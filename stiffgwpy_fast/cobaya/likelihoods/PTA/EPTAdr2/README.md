# EPTA DR2 mock resources

[中文说明](README_zh.md) | English

`../IPTA.yaml` selects the resources in this folder:

- `EPTA_dr2new_mock.dat`: sample values loaded by the `IPTA` adapter.
- `freqs_dr2new.txt`: corresponding frequency bins, one value per line.

The adapter uses the `Nfreqs` option from its YAML file when evaluating these
inputs. Keep file names and paths aligned with that configuration. The resource
contents are unchanged; this guide does not assert external provenance.
