# SGWB 计算误差预算（physics-first，2026-08-30）

本文件把 SGWB 的每个物理/数值环节拆开，逐一标记误差来源、当前量化估计、已知缺口，并区分
“引擎误差”和“共享模型/网格误差”。写作目的：后续所有算法优化都以「提升真实精度」为目标，
而不是以「更接近 LSODA」为唯一判据（LSODA 本身不是真值）。

## 0. 信号链路

```
inflationary tensor spectrum
  → primordial tensor mode (A_t, n_t, r)
  → reheating (MD, sigma=1)
  → stiff era (w=1)
  → radiation/matter transition (sigma=4/3 → ...)
  → transfer function (tensor mode equation)
  → Omega_GW(f)
  → integrated rho_GW = ∫ dlnf Omega_GW
  → Delta N_eff / kappa_r
```

## 1. 各环节误差来源与量化现状

| # | 误差类别 | 环节 | 当前量级（default 点） | 缺口 |
|---|---|---|---|---|
| 1 | truncation / 截断误差 | 频谱归一化、超视界近似 | 起点 z0 处 x=0, y=e^z0 的误差 ~O(e^{z0})，取 z0≤-3 已可忽略 | 未做 z0 收敛扫描 |
| 2 | ODE 离散误差 | tensor 方程 | fast 中点 Magnus 同网格 vs LSODA ~1e-5（ΔN_eff）；h→0 时引擎差收敛 | 中点法为二阶；未确认高阶方案（WKB/adaptive） |
| 3 | 积分/求积误差 | ∫dlnf Ω_GW | 同网格 Simpson vs SciPy ~1e-12；freq_res=1.0 vs 2.0 对 ΔN_eff ~1e-4 | 无 quadrature error estimate |
| 4 | 插值误差 | 热历史/σ 样条 | FD 查表 vs quad ~1e-11；σ 样条在瞬时再加热拐点 ~1e-3 | σ 网格误差未做拐点局部加密消融 |
| 5 | 渐近尾部近似误差 | 深亚视界尾部 | z_tail=5 贡献 ~3.8e-3（ΔN_eff 相对）；z_tail=7 → 2e-5 | 无匹配误差估计；无 WKB 高阶振幅/相位修正 |

## 2. 关键发现（来自现有审计）

1. **fast 与 LSODA 求解同一离散问题**：同网格下 ΔN_eff 差 ~1e-5（h=0.01），h=0.00125 时降到
   ~2.6e-7。故“fast≈LSODA”只证明引擎一致，未证明连续极限正确。
2. **共享 σ 网格误差 ~0.73%（h=0.01）**：来源于瞬时再加热边界 σ=1→4/3 阶跃被三次样条离散，
   LSODA(h=0.01) 与 fast(h=0.01) 对细网格参考的偏差几乎相同（7.32e-3 vs 7.34e-3）。
3. **解析尾部误差 ~0.38%（z_tail=5）**：两个引擎共用同一尾部公式；z_tail=7 降到 ~2e-5。
4. **默认设置相对深收敛参考合计 ~0.3-1%**：σ 网格 ~0.73% + 尾部 ~0.38% ≫ 引擎 ~1e-5。
5. **σ 网格路径在 1e-3 精度以下没有唯一渐近值**：h→0 时出现 ~1e-3 非单调振荡（样条过冲伪影），
   与 fast 引擎无关（两引擎同网格逐位一致）。
6. **深参考在 LSODA 下不可用**：z_tail≥15 + 细网格在 scipy solve_ivp 内存/时间不可行；现有
   深参考由 fast(h=0.00125,z_tail=15) 提供。

## 3. 结论与下一步方向

要让「真实精度」超过 LSODA，必须处理两个共享误差主源，而不是去逼近一个本身带 ~1% 网格偏差的
LSODA 参考：

- **σ(N) 精确评估**（消除再加热拐点的三次样条过冲）：用分段精确的 σ(N) 求值器替代固定步长网格
  上的样条。
- **深亚视界 WKB 渐近解 + 匹配误差估计**（消除振荡积分误差，并提升尾部精度）：在 overlap 区验证
  解析解匹配、自动判定渐近 regime、给出匹配误差界后停止振荡积分。
- **horizon-crossing 自适应步长**（k≈aH 自动细化）：把高精度积分集中在真正敏感的 O(1) 区，其余用
  解析/WKB 处理。
- **曲率感知自适应频率采样**：在谱膝/再加热特征/stiff 增强附近加密，平滑区稀疏，避免低频陡尾
  单通道 0.5 dex 欠采样。
- **高精度求积 + 误差估计**：用自适应 Gauss-Kronrod / 高阶样条给出 quadrature error，而非单一积分值。

> 原则：先回答“为什么这个数值算法在这个物理 regime 中正确”，再回答“怎样利用物理结构让它更快”。

## 4. 高精度参考的直接量化（2026-08-30，见 `audit_reference.md`）

新建的独立参考管线（连续 σ(N) + DOP853，`stiffgwpy/reference.py`）把“共享网格偏差”从 ~0.73%
直接量化为 **约 1% 的集成 ΔN_eff 低估**：

| 引擎 | DN_gw（default 点） | 相对 reference |
|---|---:|---:|
| reference（连续 σ） | 0.00227081 | 0（锚点） |
| lsoda（h=0.01） | 0.00224921 | −0.95% |
| fast（production） | 0.00224081 | −1.32% |

即 fast 与 LSODA 方向一致地低估 ΔN_eff（两者共用 σ-kink 样条），而 reference 的 ODE 自身已收敛到
~1e-7 dex。这证实：**提升真实精度的第一优先项是消除 σ-kink 网格偏差，而不是让 fast 更接近 LSODA。**

## 5. 浮点/取消误差审计（§七，2026-08-30）

对 fast 求解器在极端参数下做压力测试（`tests/test_physics_limits.py::test_float_robustness_extreme_params`）：

| 参数 | DN_eff | log10 Ω_GW 范围 | NaN/Inf |
|---|---:|---:|---|
| baseline | 2.24e-3 | −20.8 ~ −7.9 | 0/0 |
| tiny_r (1e-8) | 2.35e-9 | −24.8 ~ −13.9 | 0/0 |
| low_T_re (1e1) | 4.97e-8 | −30.1 ~ −12.6 | 0/0 |
| tiny_kappa10 (1e-8) | 4.82e-9 | −28.8 ~ −12.9 | 0/0 |
| huge_stiff (1e3) | 无（guard） | — | 共享物理护栏拒绝，非数值失败 |
| blue_tilt / cr0-highn_t | 无（guard） | — | 同上 |

结论：

1. **无 NaN/inf 溢出**：重标定变量 `xh,yh`（S2=exp(Psi)）已把 σ 项解析吸收，避免了大数相减/指数爆炸；
   深亚视界 `exp(z)` 在 z~5-7 时 ~O(1000)，安全。
2. **无下溢**：log10 Ω_GW 最小约 −30.1（Ω≈1e-30），远在 double 安全区上方；`log10OmegaGW = log10(Ogw−Oj)`
   已加 `max(..., 1e-40)` 下限，避免超视界负值产生 NaN。
3. **无危险消去**：物理可观测区（模式已进入视界）Ogw≫Oj，不做近相消；只有超视界低 f 区（本身物理
   病态、对 ΔN_eff 无贡献）会出现 Oj 与 Ogw 相消，该区已单独说明。
4. **极端 stiff 由共享 `DN_eff>5` 护栏拒绝**，返回 None（loglike→−∞），不污染后验，与引擎无关。

结论：**当前实现未发现需要 log-domain/任意精度重写才能修复的浮点缺陷**；但为把 Ω 下探到更小量级或
推更大 k/N 时更稳健，可在后续阶段把 `scaled_step`/尾部公式改为归一化（无量纲）形式，作为加固项。
