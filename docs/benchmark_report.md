## 1. 项目是做什么的

`stiffGWpy` 计算 **ΛCDM + 刚度（stiff）物质 + 原初引力波（SGWB）** 的宇宙学模型：

- 主类 `LCDM_SG`（`stiff_SGWB.py`）：给定宇宙学/暴胀/再加热参数（`r`, `cr`, `T_re`, `kappa10` 等），自洽求解
  - 膨胀历史（辐射 + 中微子 + 刚度物质 + Λ），`gen_expansion()`
  - 每个频率通道的张量扰动运动方程（LSODA 刚性 ODE），`run_SGWB()`
  - 对所有频率的频谱做 Simpson 积分得到引力波能量密度，`int_SGWB()`
  - 二分法迭代 `Delta N_eff`（SGWB 对额外辐射度的贡献）直到相对收敛判据 `1e-4`
- 输出：`log10OmegaGW(f)`（原初引力波谱）、`DN_gw(N)`、`kappa_r`、`hubble(N)`、`g2`、`w2` 等
- 配套：`global_param.py`（常数与热历史样条）、`functions.py`（费米-狄拉克积分、LSODA 求解器）、`LCDM_stiff_Neff.py`（基础宇宙学类）、`cobaya/`（MCMC 似然接口）

## 2. 原始实现性能剖析（基线 r=1e-2, cr=1, T_re=2e3, kappa10=1e-2）

| 阶段 | 耗时 | 占比 | 说明 |
|---|---:|---:|---|
| `gen_expansion` | 0.20 s | 0.9% | Python 循环生成膨胀历史（~7000 点） |
| `construct_f` | 0.001 s | 0.0% | 构造采样频率网格 |
| `run_SGWB` | 21.3 s | **93.1%** | 每个频率通道一个 LSODA 刚性 ODE 求解（4 进程池） |
| `int_SGWB` | 1.39 s | 6.1% | 逐列 scipy.simpson 频谱积分 |
| **合计** | **22.9 s** | 100% | 2 次迭代收敛 |

瓶颈非常集中：>93% 的时间花在 `scipy.integrate.solve_ivp(method='LSODA')` 对 ~240 个频率通道逐一求解刚性张量方程上。

## 3. 加速方案（全部为非 AI 方法，未改变物理与算法结构）

新增模块 `fast_sgwb.py`，逐环节用数值手段替换，数值方案与原实现一一对应：

| 原实现 | 加速实现 |
|---|---|
| `gen_expansion()` Python 循环 + `int_FD` 逐点计算 | `gen_kernel`：numba JIT；费米-狄拉克积分预计算为均匀三次样条查表 |
| 每个频率一个 LSODA 求解（自适应步长 + 稠密输出） | `solve_kernel`：同一 N 网格上的固定步长解析旋转（Magnus 型）步进 + z>5 深亚视界解析尾部 |
| `int_SGWB` 逐列 scipy.simpson | 预计算 Simpson 权重矩阵 `Wmat`（与 scipy 同公式，含端点修正），一次矩阵乘完成全部列 |
| 逐列掩膜插值 | 粗网格列精确积分 + PCHIP 加密到细网格 |
| 4 进程池（进程启动/序列化开销大） | numba `prange` + OpenMP 线程并行（32 线程） |
| 每次迭代重建全部网格依赖量 | 跨迭代网格缓存（网格漂移 ~2e-13 < 1e-9 阈值时复用 `Wmat`/`P_t`/`fp_freq`/`ev_minus` 等） |

收敛循环、二分法、收敛判据（`1e-4` 相对误差）、`DN_eff` 处理、输出字段（`log10OmegaGW`, `DN_gw`, `kappa_r`, `hubble`, `g2`, `w2`, `f` 等）与原实现完全一致。

## 6. 使用方法

```python
from stiff_SGWB import LCDM_SG
import fast_sgwb

model = LCDM_SG(r=1e-2, cr=1, T_re=2e3, kappa10=1e-2)
model.SGWB_iter(engine='fast', fallback=True)   # 统一入口；失败自动回退 LSODA
# 或直接调用：fast_sgwb.SGWB_iter_fast(model)
```

注意：fast 路径填充核心输出（`log10OmegaGW/DN_gw/kappa_r/hubble/g2/w2`），但**不产出**
原版的 `N_hc/Th/Oj/Ogw/Opgw` 属性，不能视为 drop-in 替换。

可调参数（import 前设置环境变量）：`FAST_THREADS`（默认 = numba 检测到的可用线程数，
不再强设 32）、`FAST_COL_STEP`（默认 4，合法范围 1–8）；运行期可用
`fast_sgwb.set_threads(n)` / `fast_sgwb.set_col_step(n)`（带范围校验）。
