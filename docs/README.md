# Documentation

This directory contains maintained software and numerical-method guidance:

- `physics.md`: physical model and assumptions.
- `numerical_method.md`: solver and integration design.
- `accuracy.md`: validation scope and interpretation limits.
- `cobaya.md`: optional Cobaya adapter.
- `reproducibility.md`: environment and verification practices.
- `test_coverage_matrix.md`: core test responsibilities.

Bulk research outputs and experiment records are kept in a separate local archive. Fixed samples required by regression tests live in `tests/data/`.
