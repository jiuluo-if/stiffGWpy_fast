# 综合审计：速度与精度对比 + 后续研究重点（2026-08-30）

本文件把 SGWB 高速内核在**所有维度**上的速度与精度数字汇总成一张图，并给出**后续研究重点**。
所有数据都取自仓库内可复现的产物：

* 引擎级速度/精度：`docs/reference/pareto_default.json`（由 `scripts/benchmark_pareto.py` 生成，
  default 点，`z_tail=5` 同口径，相对**连续 σ 参考**而非 LSODA）。
* 分项误差预算：`docs/audit_error_budget.md` 第 6 节（修复后的九类分项）。
* 逐频误差：`docs/audit_reference.md` 第 7.8 节。
* 四维基准 / ODE / 尾部 / 求积误差：`docs/reference/benchmark_default.jsonl`（由
  `scripts/benchmark_reference.py` 生成）。
* 验收状态：`docs/audit_acceptance.md`。

> 核心口径：**精度一律相对独立高精度参考（`stiffgwpy/reference.py`，连续 σ + DOP853），不以
> LSODA 为真值。** LSODA 只作为“原始实现”的速度与一致性参照。

## 1. 引擎级对比（default 点，热缓存，`z_tail=5` 同口径）

数据来源：`docs/reference/pareto_default.json`。

| 引擎 | 运行时间 | 相对 LSODA | 相对参考 | ΔN_eff | 相对连续 σ 参考 | 说明 |
|---|---:|---:|---:|---:|---:|---|
| **参考**（连续 σ DOP853） | 171.7 秒 | 约 0.1× | 1× | 0.00227034 | 0（锚点） | 独立高精度锚点，非 MCMC 热路径 |
| **快内核·过渡细化**（production） | 0.282 秒 | 约 66×（加速） | 约 608× | 0.00226985 | **−0.022%** | 拐点感知，已达标 小于 1e-3 |
| **快内核·普通网格** | 0.012 秒 | 约 1541× | 约 14300× | 0.00226669 | −0.161% | 最快，但含 σ 拐点网格偏差 |
| **LSODA**（原始） | 18.6 秒 | 1× | 约 9× | 0.00226652 | −0.168% | 原始参考，与普通网格同为网格偏差 |

**关键结论**：

1. **同时更快且更准**：快内核·过渡细化相对 LSODA 快约 **66×**（单点），同时对连续 σ 参考的积分
   `ΔN_eff` 误差 **−0.022%（小于 1e-3）**，优于 LSODA 的 −0.168%。这是“精度上升且耗时下降”，
   而不是“精度≈LSODA、只降耗时”。
2. 若不考虑精度模式，只看工程极限：普通网格快到 **约 12 毫秒**（相对 LSODA 约 1541×），但精度只能到
   −0.16%。
3. `reference` 作为锚点慢 3 个数量级，只在基准点、病态点、收敛认证用，不进 MCMC。

> 注：不同机器/线程数会改变绝对运行时间，但**相对关系与相对误差**稳定；上表在同一次运行中测得。

## 2. 逐频 `Ω_GW(f)` 精度（信号区 vs 积分量，default）

数据来源：`docs/audit_reference.md` 第 7.8 节（单频 `solve_reference_mode`，同一 ΔN_eff）。

| 环节 | 量级 | 是否达标 |
|---|---:|---|
| **积分 `ΔN_eff`**（MCMC 实际依赖 `Delta_Neff_GW`） | **−0.022%** | 达标（小于 1e-3） |
| **逐频信号区** `Ω_GW(f)`（如 f=−8） | +0.2% ~ +0.4% | 未全域小于 0.1% |
| **低频尾** `Ω_GW(f)`（f 小于等于 −10） | +0.4% ~ +1%（约 4e-3~5e-3 dex） | 欠采样 |
| 高 f（f 大于等于 +4） | +2.4e-3 dex | 良好 |

**逐频正负相消**是关键：积分 `ΔN_eff` 因各频误差符号相反（低频偏正、f 约 0 偏负）而收敛到小于
1e-3，但**单频** `Ω_GW(f)` 信号区仍卡在约 0.2–0.4% —— 这是过渡细化的**逐模 Magnus 极限**，
不是网格问题。

## 9. 后续研究重点（按优先级）

以下按“**先提升真实物理精度，再提速**”的原则排列，每条都给出目标、当前障碍与验收口径。

### 9.1 逐频 `Ω_GW(f)` 信号区低于 1e-3（当前约 0.2–0.4%）—— **最高优先**

* **现状**：积分量已达标，逐频卡在过渡细化的二阶冻结-z Magnus 极限。
* **方向**：把单频原型（`reference.solve_reference_mode`）的高阶/自适应逐模积分理念移植进
  `solve_kernel`，或在强振荡区切换到 WKB 渐近解后停止积分。**关键线索**：第 7.6 节显示独立单频原型
  误差仅约 1.4e-4~8.3e-4 dex（0.03%~0.19%），优于生产内核约 6e-3 dex，且对起点深度/分段/四阶 Magnus/
  子网格密度**均不敏感** —— 说明根因可能在“内核逐模实现 vs 单频原型”的 Φ/S2 表、起点 j0/z0 或尾部
  锚点一致性，存在约 10× 偏差，**先定位这个偏差**，可能无需换数值方法。
* **验收**：逐频信号区 `Ω_GW(f)` 相对误差小于 1e-3，且 h 收敛进入单调渐近区。

### 9.2 WKB 深亚视界渐近解落地（减少振荡积分 + 提速）

* **现状**：`reference.solve_reference_mode` 已返回绝热参数 `eps_handoff=|1.5σ−1|/e^z` 与
  `matching_error_rel`；WKB 频率 `dθ/dN=e^z` 已测试验证；但**未在快内核落地**。
* **方向**：在深亚视界自动判定进入渐近 regime，用解析 `u_k≈A_k e^{-ikη}/√(2k)` 匹配并给出
  **匹配误差界**后停止振荡积分。目标：减少长振荡积分带来的相位/振幅累积误差，同时提速。
* **验收**：重叠区解析解与数值解匹配，匹配误差可估计且小于目标；深亚视界不再积分。

### 9.3 视界穿越自适应步长 + 频率空间曲率自适应（提速 + 低频尾）

* **现状**：`freq_adaptive.adapt_refine_grid`（曲率 `|y''|h²/8` 打分）与 `grid_independent_freqs`
  已实现并测试，但**未接入快内核生产路径**；`construct_f` 是当前 production 默认。
* **方向**：在谱膝/stiff 峰/再加热特征/高 f 截止/低频陡尾处自动加密，平滑区稀疏；用高阶插值恢复全谱。
  保留 `construct_f` 作基线，仅在高曲率区做自适应细化，避免 `grid_independent_freqs` 对 stiff 峰的
  欠采样（f 约 0 处 −4e-3 dex）。
* **验收**：低频陡尾单通道误差显著下降，且不破坏 stiff 峰与 `ΔN_eff`。

### 9.4 完整的参数空间验证（Sobol/LHS/edge/extreme 相对连续 σ 参考）

* **现状**：default 与 stiff（kappa10=1.0）同口径相对参考均约 −0.04%；多点扫描无 NaN。
  但**尚未**做大批量统计集的完整 reference 对标（reference 约 171 秒/点，昂贵）。
* **方向**：选代表性子集做 reference 对标，其余用 production 自洽 + 误差预算估计；或并行化以摊薄成本。
* **验收**：全集误差分布、最坏点、参数误差图，且每个最坏点的误差来源可解释。

### 9.5 收敛后的 posterior 对照（快内核 vs reference 长链）

* **现状**：点位 `ΔlogL` 已做（default、z_tail=5 同口径：快内核 0.0022698 对 reference 0.0022703，
  ΔΔN_eff=−5.44e-7，`|ΔlogL|` 依 σ_Neff 为 1.5e-5 / 1.7e-6 / 1.5e-7）。但**未跑收敛长链**。
* **方向**：同参数、同 seed，快内核与 reference 各跑一条充分收敛的链（最小 ESS 不小于 2000），对比
  后验均值/标准差/16–84%/MAP/ESS/协方差/KS/Wasserstein/KL/后验偏移/回退比例。
* **代价**：reference 约 171 秒/点，完整链需数小时 —— 需用户批准的长时运行。`scripts/mcmc_compare.py`
  已就绪，支持 `engine`/`--samples`/ESS 门槛。
* **验收**：后验在统计意义下与高精度 reference 一致，最小 ESS 不小于 2000。

### 9.6 尾部 `z_tail` 共享近似的同口径化与自适应尾部

* **现状**：`z_tail=5` 对 `7` 差约 0.35%；production 默认 `z_tail=7`，reference 默认 `z_tail=5`，
  造成双引擎对比时额外约 0.35% 的表观差。
* **方向**：生产与 reference 默认统一 `z_tail`（或让尾部事件切换自动匹配），并给出**匹配误差估计**
  （替代当前固定的渐近尾部）。
* **验收**：双引擎同口径下 `ΔN_eff` 差收敛到求解器误差（约 0.02%）而非尾部差（0.35%）。

### 9.7 清理非单调收敛态，确立干净收敛阶

* **现状**：`sigma_exact` 的模型偏差随 h 非单调（0.40%→0.21%→0.44%→0.25%），无干净二阶收敛。
* **方向**：与 9.1/9.2 一起，用更高阶/自适应积分器替换二阶 Magnus；对 h=0.02…0.00125 做
  过渡细化收敛扫描，目标稳定渐近。
* **验收**：收敛斜率与理论阶一致，无网格相位非单调伪影。

## 10. 一句话总结

当前状态：**积分 `ΔN_eff` 已达小于 1e-3（−0.022%）且相对独立连续 σ 参考衡量，在帕累托上同时优于
LSODA（更快+更准）**；核心 MCMC 依赖量已进第 13 节门槛。剩余大项集中在**逐频 `Ω_GW(f)` 信号区
约 0.2–0.4%**（需更高阶/自适应逐模积分或 WKB 落地）、**完整参数集与收敛后验链**（昂贵长任务）。
下一步最高优先：定位“内核逐模 vs 单频原型”的约 10× 偏差（第 7.6 节），很可能不用换数值方法即可把
逐频精度推进到小于 1e-3，再叠加 WKB 与自适应频率采样做提速。
