# 极小振幅频率网格与尾部误差筛查

日期：2026-11-15
状态：已重算 235/469/937 点直接频谱、固定背景映射、Fast z5/z8 和 Reference z8/z10；**Fast z_tail=8 在本样本三个离散网格上的最大谱误差均低于 `4e-4 dex`，根映射残差低于 `2e-6`。** 这不是参数域认证，也尚未证明 z8 适合作为生产配置。Fast z_tail=5 的 937 点网格仍有单点超差。

## 基准和方法

实验基于 `fast_v0.2` 的 `8dfbee54`，修复验证收集后提交为 `d6ddbb2bff44959c6f65c18db88368ac574bd30b`。Fast 源文件 SHA-256 为 `5bfde604e778abee8b955b61549bbd805026943a1235686739215d60f54c6449`；Reference 源文件 SHA-256 为 `4e2eb80709da944923206a840c0864d454faad9b51dc3fb9ebfda90abe460536`。

唯一样本参数：`r=1e-316`、`A_s=2.100549e-9`、`n_t=17.38`、`cr=0`、`T_re=2000`、`DN_re=10`、初始 `DN_eff=0`。Fast 直接传播原生 235、469、937 个频率点；469 和 937 分别由前一级每个相邻 log10 频率区间直接插入中点，不使用粗网格插值代替高分辨率求解。

**实验 harness 勘误：**首轮固定背景 Fast 脚本在 `DN_eff=0` 下先执行 `gen_expansion()`，之后才在包装函数内设置目标背景；`tol=0.99` 的首轮传播因此使用了 `DN_eff=0` 背景，而 Reference 使用目标 `DN_eff`。同一问题也影响了当时的尾部、步长和交接诊断。首轮所有固定背景 Fast/Reference 频谱差、尾深残差和步长结论均作废。修正后的脚本先设置目标 `DN_eff` 再生成背景，并在后续展开时保持背景锁定；本文件以下固定背景数据均来自修正后的重新运行。Fast 自洽根（未锁背景）保持原值。生产 Fast/Reference 源码没有变化。

Reference 使用 `r=A_s=1,n_t=0` 的单位振幅传播，再按目标 `log(r A_s)+n_t(ln(10) f−ln(f_piv))` 逐点缩放。对此 `cr=0, DN_re=10` 切片，物理振幅模型与单位振幅模型在相同 `DN_eff` 下的 `Nv`、`f_hor` 完全相同；这项等价性不外推到 `cr>0` 或由 `A_t` 决定暴胀终点的分支。Reference 尾部取 `z_tail=8, rtol=1e-9`，Fast 基线取 `z_tail=5`。

Fast 根从 235 到 469 变化 `−2.22e-6` 相对，从 469 到 937 变化 `−8.71e-8` 相对。固定在 235 点 Fast 根时，Fast 固定背景映射从 235 到 469、937 分别变化 `−2.22e-6`、`−2.30e-6` 相对；Reference 映射分别变化 `−1.61e-6`、`−2.82e-7` 相对。Reference 在每个 Fast 自洽根处的映射残差分别为 `−2.29e-8`、`−6.36e-9`、`−1.17e-8`。这些都是离散映射残差，不是区间根误差界；本实验未证明固定点收缩或根唯一性。

Fast z5 的 937 点最大误差出现在新增中点 `log10(f/Hz)=−16.291944809`，而其相邻 937 节点误差为 `4.30e-4` 与 `6.48e-4 dex`。同样固定背景下将 Fast 尾深增至 z8 后，对 Reference z8 的 235/469/937 三网格最大 / P95 误差变为 `0.000390/0.000148`、`0.000390/0.000148`、`0.000468/0.000148 dex`；再用完整 Reference z10 重算三网格，Fast z8 最大 / P95 误差分别为 `0.000353/0.0000223`、`0.000380/0.0000228`、`0.000391/0.0000233 dex`。Reference 自身 z8→z10 最大 / P95 谱变化为 `0.000207/0.000142 dex`、`0.000207/0.000142 dex`、`0.000207/0.000142 dex`；对应映射相对变化为 `5.31e-6`、`3.72e-6`、`3.68e-6`。Fast z8 映射相对 235 点自洽根分别偏差 `+1.15e-6`、`−1.65e-6`、`−1.96e-6`。因此 z8 在本样本三张直接网格上通过 root/spectrum 离散筛查；尚无 469/937 网格上的根区间界或参数域留出认证。z8 运行目前只有单次计时，没有相同资源下的重复 P50/P95，仍不作为生产配置变更。

Fast 的对数谱在三个网格上均为全有限值；物理线性 `(Ogw−Oj)` 却分别有 14、28、55 个精确零值。零值节点的对数谱范围为 `−323.64` 至 `−367.44 dex`。正次正规数节点中，线性相减与专用正值对数基础量最多相差 `0.00253 dex`；937 点最差正次正规节点差 `0.0514 dex`，其线性值只有 `1.5e-323`。这说明终端日志保留了线性数组无法表示的尾部信息，而 `DN_gw` 仍由线性数组积分；两种输出在尾部不能逐点互换。

## 插值、Reference 警告和尾部

- Reference 的全局归一化被积函数有 13、25、49 个节点在 235、469、937 网格下舍入为精确零；每次 `integrate_spectrum` 均重现 4 条 `overflow encountered in divide` 警告。该函数的缩放分支只处理非零次正规数，不能恢复这些由对数归一化产生的零。
- 直接 Reference 积分在 937 点的估计相对求积误差约 `1.1e-14`，半密度插值差估计约 `2.83e-7`。二者不消除斜率警告，也不是对插值真误差的证明。
- 作为明确标记的诊断，线性 PCHIP 对新增节点分别有 12/24/36 个零预测（235→469、469→937、235→937）；有限可比节点的最大绝对误差分别为 `8.59`、`3.99`、`12.58 dex`。因此 235 点插值完全不能冒充 469/937 点直接频谱。极小归一化值上的这些 dex 比值应视为表示范围诊断，不作为显著积分误差。
- 对 log-PCHIP 进行了直接新增节点偏差检查。它不再发出除法溢出，但 235→469 新节点最大/P95 谱差为 `0.462/0.00583 dex`，469→937 为 `0.185/0.00295 dex`，仍超过最大谱差门槛。对应映射积分偏差只有 `−3.07e-6` 和 `−3.53e-7`，显示积分吻合不能替代谱准确性。**拒绝直接将 log-PCHIP 用作 Reference 修复。**
- 另实现了按对数割线、SciPy 相同调和平均、相同端点公式和形状裁剪构造的稳定线性 PCHIP 诊断器。对普通范围样本，它与 SciPy 的节点间曲线及积分在 `2e-12` 内一致；对当前 235/469/937 保存的 log 谱，稳定积分映射与 Reference 原 PCHIP 结果相对差 `≤1.8e-15`，稳定算法没有 RuntimeWarning。它恢复精确小节点并移除调和平均倒数溢出，但新增节点谱误差仍与普通线性 PCHIP 相同并超过门槛；它是 Reference 诊断候选，不是频率加密或 Fast 精度改进。
- 固定背景的 z5/z8 同网格对照覆盖 235、469、937 点。尾深从 5 增至 8 后，最大误差分别下降至 `0.000390`、`0.000390`、`0.000468 dex`。937 点尾深/步长分解在异常节点上显示：z5 下 `h=.005` 误差 `0.002385 dex`，将 h 降至 `.000625` 仍有 `0.002377 dex`；z8 下 `h=.005` 误差降至 `3.54e-6 dex`，继续减小 h 的误差处于 `4.1e-8` 至 `2.95e-7 dex`。在这个节点上，时间步细化不是主修复因素，尾部近似深度是主因素。该结论只适用于本频率节点，不构成全域 WKB 界。
- 对 z5/z8 最差交接节点 `log10(f/Hz)=−12.642` 直接读取 Reference z8/z10 与 Fast 终端矩：Fast z8 对 Reference z10 的谱误差为 `0.000353 dex`；该节点 `z_today=13.395`，相位尾权重为 0。根据 Fast 同一交接状态重建 `assemble_tail` 的 `Opgw_today`，预测值与实际线性缩放结果比值为 `0.99999999999994`；Fast/Reference z8 `Opgw` 比为 `1.000729`。这验证了该节点的解析尾缩放与生产实现一致，但不构成所有状态或相位修正分支的证明。
- 另一项局部频率加密直接在 937 网格异常点两侧求解 15 个 1873 等效中点；Fast z8 对 Reference z10 最大 / P95 差 `1.44e-5/1.22e-5 dex`。由原 937 点 Reference 曲线 PCHIP 预测这些直接值的最大 / P95 误差为 `0.00882/0.00674 dex`。因此局部曲线不能由粗节点插值可靠代表；这 15 点不替代完整 1873 网格自洽积分。
- Reference 自身 `z_tail=8→10` 在三个网格上均重现每次积分 4 条 `overflow encountered in divide` 警告；参考尾差数据完整记录在原始 JSON。尾部变化只对该参数点和这些离散节点有据，不构成其他参数下的误差界。
- 同根、同 937 点网格、单线程交替 12 对 z5/z8 计时：z5 P50/P95 `0.1299/0.1351 s`，z8 `0.2034/0.2128 s`，z8/z5 P50 时间比 `1.566`。两组重复谱 spread 均为 0，最大 RSS 约 `173.7 MB`；固定根映射绝对残差分别 `6.31e-8` 与 `5.38e-8`。首个 Fast 调用 z5 冷启动 `0.446 s`，随后 z8 首次档位调用 `0.208 s`（Numba 已由前一调用预热，不能视为独立冷启动）。因此 z8 带来本样本尾部准确性改善，但耗时约增 `56.6%`，不是性能优化，也无充分依据改生产预设。
- 最差节点直接状态对照现已复刻 Fast 正式配置 `phase_max=0.25`、`kink_split=True`、正确的固定背景与分段原函数。该模式在 `N≈22.735` 起步，`cr=0, DN_re=10` 的 kink 在 `N=10`，传播不跨 kink；z8 匹配节点上 `h=.005` Fast/Reference 二次范数差为 `−4.99e-6`。以 Fast 同状态按 `assemble_tail` 公式重建的 `Opgw_today` 与生产 Fast 线性结果比值为 `0.99999999999994`；该点相位尾权重为 0。此结果验证一个实际模式的解析尾尺度组装，不证明其他相位分辨权重分支。

PCHIP 内点导数是相邻割线的加权调和平均；零割线或异号割线时导数置零。正数整体缩放具有齐次性，但不能让已在构造归一化数组时舍入为零的节点恢复。可研究的下一步是直接从 log 样本稳定计算割线与调和平均，并验证得到的同一线性 PCHIP 曲线及积分；log-PCHIP 是不同插值器，必须用这些直接细网格数据另行衡量偏差。算法公式见 SciPy [`PchipInterpolator`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.PchipInterpolator.html) 和 Fritsch–Butland [原始论文](https://doi.org/10.1137/0905021)。

## 下溢分支和数学边界

在固定背景下，张量模方程是线性齐次方程，Fast 的 `P_t` 只乘到模式终端组装量，因此单位振幅传播后恢复 `P_t` 在精确算术中等价。浮点实现先恢复线性 `Ogw/Oj/Opgw`，再对 `(Ogw−Oj)` 做 PCHIP 积分；对数谱单独由正的基础信号和 `log_P_t` 重建。因此“对数谱有限”不保证积分节点仍可表示，若映射最后变成精确零，Fast 会失败而不是报告精确零振幅解。

精确零输入由 `r=0` 或 `A_s=0` 且 `cr<=0` 定义；非零次正规 `r A_s` 下溢不是精确零。`cr=0` 的对数振幅回退可分别计算 `log(r)+log(A_s)`。`cr>0` 的背景依赖张量幅度，不能通过同一回退忽略；若其存储 `A_t` 已为零，Fast 保持失败。背景原函数 `S2=exp(Psi)` 另外在传播前检查非有限值；本实验没有触及或扩展 `S2` 溢出域。

相位分辨尾部单元测试覆盖精确辐射解析解，但目前的 ripple 权重、尾后相位积分、部分周期权重和三终端矩同权混合尚未形成统一 WKB 余项/交接误差界。本轮没有修改这些逻辑，也没有接受相位尾部候选。
