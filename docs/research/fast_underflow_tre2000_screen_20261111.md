# Fast 极小张量振幅：T_re=2000 三乘三筛查

日期：2026-11-11

状态：完成本轮有限网格筛查；结果支持继续扩域评估，不构成连续参数域认证。

## 目的与设置

检查张量振幅输入进入 binary64 次正规数区时，Fast 对固定高再热温度切片的数值表现。使用 `r ∈ {4.985023e-317, 9.946429e-317, 1.98457346e-316}` 与 `n_t ∈ {17.30, 17.375, 17.45}` 的 3×3 网格，`T_re=2000`。Fast 使用构造频率网格、尾部参数 5；Reference 使用 `z_tail=8`、`rtol=1e-9`、3 次自洽根迭代。Reference 通过单位振幅计算后按输入对数功率精确缩放，避免目标振幅在线性浮点表示中下溢。

比较门槛沿用本轮筛查标准：绝对根差不超过 `2e-4`，全频谱最大差不超过 `1e-3 dex`。根差根据 Fast 输出根与缩放 Reference 自洽映射估计值计算。每点均比较 235 个共同频率。

## 警告与限制

- Reference 插值阶段反复出现 SciPy `PchipInterpolator` 的 `RuntimeWarning: overflow encountered in divide`。本次 9 个输出均完成，所有对数谱值有限；警告仍需在独立 Reference 数值审计中解释，不能视为已消除。
- 每个 Reference 点仅做 3 次根迭代；报告的根差是数值自洽映射估计，不是经区间算术认证的根误差界。
- 这是 9 个离散点，不能证明网格之间或更大参数域的连续正确性，也不能据此宣称完整域认证。
- 本轮验证对象是极小振幅下的稳定性和适用范围，不是新的求解器速度优化。
