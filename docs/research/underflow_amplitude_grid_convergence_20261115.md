# 下溢振幅阶梯的频率网格与根对照

日期：2026-11-15

## 设计

选取 `r={1e-316,1e-318,5e-324}`，固定其余参数为既有高蓝倾斜 `cr=0,n_t=17.38` 样本。在直接嵌套的 235/469/937 log 频率节点上，分别计算 Fast 自洽根，并在各振幅自己的 235 点根处固定背景计算三个网格映射。另在每个振幅的 235 点根上独立计算单位振幅 Cartesian Reference，并以 `cr=0` 的线性振幅齐次性恢复该振幅的频谱和积分。Reference 只在 235 点运行；未将 235 点插值冒充更密 Reference 直接解。

## 结果

| `r` | 235 根 | 469 相对根变化 | 937 相对根变化 | 235 根处 Fast z5 / Reference z8 最大谱差 | 映射相对差 |
|---:|---:|---:|---:|---:|---:|
| `1e-316` | `0.02741222809` | `−2.2160e-6` | `−2.3031e-6` | `0.000480448 dex` | `8.3519e-7` |
| `1e-318` | `0.0002741219423` | `−2.2160e-6` | `−2.3031e-6` | `0.000471680 dex` | `8.3479e-7` |
| `5e-324` | `1.35434404e-9` | `−2.2160e-6` | `−2.3031e-6` | `0.000474623 dex` | `8.3517e-7` |

三个固定背景 Fast 映射从 235 到 469 的相对变化均为约 `−2.2160e-6`，到 937 点均为约 `−2.3031e-6`；因此 469→937 的增量约 `−8.71e-8`。振幅降低 10 至约 308 个数量级时，绝对根按振幅变化，而相对频率离散误差几乎不变。235 点 Reference 映射本身对固定根残差约 `−8.35e-7`。这些根残差是观测到的离散映射差，不提供根唯一性或收缩界。

每个 Reference 样本仍产生 4 条 `overflow encountered in divide` 警告，且 13 个归一化积分节点为精确零；该警告来自 Reference 的线性 PCHIP 导数算术，未屏蔽。直接 `Reference` 的 quadrature relative estimate 约 `1.11e-14`，interpolation relative estimate 约 `1.60e-5`。这两个估计都不是频谱插值误差界，且不会消除 PCHIP warning。

## 判定和未决项

离散筛查支持 Fast 在所选三个非零下溢振幅上的根/网格行为连续，且每个 235 点根处的 Fast 谱差低于 `1e-3 dex`、积分相对差低于 `2e-4`。没有发现缩放误差随振幅变小而恶化。仍不能对全阶梯宣称通过：469/937 点没有在每个新自洽根重新跑 Reference；也没有在各样本做 Reference 尾部 z8→z10、Fast 根容差扫描或独立留出。PCHIP warning 仍是 Reference 实现的可观测问题。
