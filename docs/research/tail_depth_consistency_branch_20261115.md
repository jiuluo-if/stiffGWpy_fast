## 参数和背景边界

参数为标准密度/Hubble 背景、`r=0.01`、`A_s=2.100549e-9`、`cr=1`、`T_re=2000`、`kappa10=0.01`、初始 `DN_eff=0`。Fast 根闭合为 `DN_eff=0.0022636474124195006`，`dn_converged_delta=0`；一致性关系推导 `n_t=-0.00125`、`N_inf=68.81383977195439`、`N_re=37.7723412841054`，再加热事件 `N_re_abs=31.04149848784899`。物理 `A_t=2.1005489999999998e-11`，Fast 与 Reference 复算的 `A_t` 完全一致。

Reference 从真实 `cr=1` 参数和物理振幅直接传播；没有使用 `r=A_s=1` 单位振幅替代。频率网格有 76 个原生节点，单线程。

## 尾深结果

| 求解 | `DN_gw` 映射 | 相对 Fast 根残差 | Fast/Reference z10 最大 / P95 谱差 |
|---|---:|---:|---:|
| Fast z5 | 0.002263647412499695 | `3.54e-11` | `0.001429/0.000343 dex` |
| Fast z8 | 0.002263638256561386 | `−4.04e-6` | `0.000358/0.000245 dex` |
| Reference z8 | 0.002264313648375597 | `+2.943e-4` | z8→z10 最大 / P95 谱变化 `0.000165/0.000158 dex` |
| Reference z10 | 0.0022636586328683753 | `+4.957e-6` | 作为本次尾部基准 |

Fast z5 最大谱差超过 `1e-3 dex`；z8 在该点通过最大谱差门槛。Reference z8 的映射根残差略高于 `2e-4` 根门槛，z10 后降至 `4.96e-6`。因此谱误差与固定点根误差必须分别验收，即使 z8 的逐频谱误差较小，也不能据此认为 Reference z8 的根已收敛。

这是一个 `cr>0`、常规物理振幅、离散网格的验证点；它不验证 `A_t` 下溢后的边界，也不构成一致性分支的参数域认证。当前观测支持进一步检查 z8 对一致性分支有精度价值，但尚不足以改变生产尾深；增加约 56.6% 的运行成本来自另一 `cr=0` 样本，不能直接外推到此分支。
