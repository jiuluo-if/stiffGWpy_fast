基线 3eb9589952833301b197b650a90d0709a5b229cc，实验限定为单 Agent，同机固定线程。
1. 重放 402 点记录中的背景与传播失败，长再热资源记录另外重放，先判正性、截止及完整输出可表示性。
2. 先测试恒等变换，后实现候选。对于再加热前的物质主导分支，视界为线性函数，禁止在此处先计算转折后的辐射背景。张量模式只在 j0 及以后有数值初态；选在所有模起点之前的共同时刻作局部时间原点，可在不改变初态和物理输出的条件下消去尺度因子。推导、不同切片上独立核验、频率积分收敛与旧区计时是晋级条件。
3. 处理真实末端尖峰须另外检查 σ 积分误差，不能对已失真的 Ψ 仅仅重标。检查有符号闭合项和连续精度。
4. 在同一公开入口验证扩域、留出和性能，完整质量门通过后才发布。此计划为本地研究工作底稿。
