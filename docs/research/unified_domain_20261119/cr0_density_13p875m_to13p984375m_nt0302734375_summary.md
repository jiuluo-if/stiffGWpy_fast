# CR0 负倾斜带密度上界扩展至 13.984375M

## 参数盒

固定 `cr=0`、`Omega_ch2=0.1201075`、`T_re=2000 K`、`r=0.01`、`kappa10=0.01`，筛查
`Omega_bh2 ∈ [13.875e6,13.984375e6]`、`n_t ∈ [-0.0302734375,0]`。CR0 下输入 `n_t` 独立。

生产 Fast、Reference 与物理方程均未改。复用已部署的尺度归一化背景和传播状态路径。Reference 映射 `F_ref(DN_eff)` 的固定点根误差按 `|F_ref(DN_fast)-DN_fast|/|F_ref(DN_fast)|` 评估。

## Fast 扩域对照

11 个规则格点/内部点加独立 Sobol seed `20261152` 的 8 个点，共 19 个同输入样本。旧 Fast 失败基线 `872a70dc5ab3bb2ff9d3c0d78f05850341b42a45` 为 `0/19`，新 Fast `19/19`；旧失败全部是 `nonfinite_background_primitive`。新 Fast 样本 H² 正且有限，最小值 `0.45321399346`，截止有限、75 频点完整、零 warning。

盒外的 `14e6,-0.0302734375` Reference 首次映射失败，因此没有把密度上界推进到 14M。新验收盒在已有低密度子盒基础上向密度方向扩展至 13.984375M，与 14M 更近但保留参考可积分边界。

## Reference 精度

设置保持 `z_tail=8`、`rtol=1e-9`、`self_consistent=False`。下密度边界、内部与新上密度边界的首次映射最大 root 残差 `1.64738e-5`，最大 75 频谱差 `6.38250e-4 dex`。独立 Sobol 点 root 残差 `1.40476e-5`、谱差 `6.22393e-4 dex`。新上密度边界再进行一次 Reference 闭合映射成功，残差 `1.08672e-7`。

这些低于 root `2e-4` 与频谱 `1e-3 dex` 门槛；它们是有限代表样本，不证明矩形中每一点。

## 性能

相同硬件、双线程 TBB、持久进程，每例 3 次预热并进行 500 对交替完整 Fast 求解。基线 `59a23aec2300f08b50124d7f35dec4b228388d37`，候选 `7c63e54de1146d35d535a3d717f6de6957ad706d`。新增区域最大 P50/P95 比 `0.997097/1.000816`；可信 CR0 控制 `1.002412/0.991652`。root、频率网格和谱逐位相同。首个冷启动求解基线 `20.585 s`、候选 `20.715 s`。
