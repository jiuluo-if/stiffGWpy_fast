# CR0 高密度近零倾斜区域：13.875M–14M

## 本轮范围

参数盒为 `cr=0`、`Omega_ch2=0.1201075`、`T_re=2000 K`、`r=0.01`、`kappa10=0.01`，在 `Omega_bh2 ∈ [13.875e6, 14e6]` 与 `n_t ∈ [-0.015625, 0]` 上做有限样本筛查。CR0 下输入 `n_t` 独立，不应用 `cr>0` 的倾斜指数关系。

本轮没有修改生产 Fast 或 Reference 源码。采用的稳定背景缩放与张量/WKB状态表示已在基准提交中；这次只测量其在旧 Fast 曾因 `nonfinite_background_primitive` 失败的相邻高密度带上的行为。

## 数值方法与有效性

背景方程和真实再加热转折条件不变。已部署的背景表示通过尺度归一化避免先构造 `exp(N_inf-N)` 及其高次幂，再形成最终背景量；张量传播保持原有归一化状态/WKB匹配路径。本轮可复查的范围依据是同输入旧/新 Fast 对照，不把数值表示改善等同于物理方程改变。

接受盒内 11 个规则格点/内部点和 8 个独立 Sobol 点共 19 点均得到 `H²>0` 且有限、有限截止、完整 75 频点、零 warning；旧 Fast 在相同 19 点全部以 `nonfinite_background_primitive` 失败，新 Fast 全部成功。H² 最小采样值约 `0.45321399346`。这些是离散覆盖结果，不证明盒内每一点都有效。

另筛过较宽的 `[13.75e6,14e6] × [-0.015625,0]` 盒，Fast 结果同样 `0/19→19/19`；但 `13.75e6, n_t=-0.015625` 的 Reference 积分因步长小于浮点间距而失败。因此较宽盒不纳入精度验收。本轮把精度盒下界收窄至 `13.875e6`，并在该低密度低倾斜边界重做旧/新 Fast 屏幕及 Reference 核验。

## 精度

Reference 未修改，设置保持 `z_tail=8`、`rtol=1e-9`、`self_consistent=False`。三个边界/内部样本在 Fast 根处的 Reference 固定点残差最大 `1.58052e-5`，最大谱差 `6.35822e-4 dex`。一个独立 Sobol 留出点的单次 Reference 映射残差为 `1.30034e-5`，75 个有效频率的最大谱差为 `6.35931e-4 dex`。均低于 root `2e-4` 与谱差 `1e-3 dex` 验收线。

该 Sobol 点的额外 Reference 闭合映射可复现步长小于浮点间距错误。其第一次映射已达到固定点残差门槛，但更深的 Reference 闭合不能完成；保留此限制和原始诊断，不把它描述为已完成深迭代 Reference 闭合。

## 性能

基线为 `59a23aec2300f08b50124d7f35dec4b228388d37`，候选为 `d4ee1b9c8f9fad401c5e22c2316094a608074727`。使用同一硬件、双线程、TBB、两个持久进程、每例 3 次预热和 500 对交替的完整 Fast 求解。新增区域样本的最大 P50 比为 `1.005285`，最大 P95 比为 `1.015309`；可信 CR0 控制点 P50/P95 比为 `1.000268/0.983095`。输出 root、频率网格和谱逐位一致。首个冷启动编译求解耗时为基线 `20.924 s`、候选 `21.766 s`（候选约慢 4.0%）；预热后新增样本稳定在 5% 回退门槛内。

## 结论与边界

本轮在高密度末端新增了 `[13.875e6,14e6] × [-0.015625,0]` 的有限采样支持；这一段与已验收的 `[13e6,13.984375e6] × [-0.5,0]` 相邻重叠。失败类型图、Reference 精度分布和运行时间对照见 `cr0_density_14m_upper_nearzero015_slice.png`。

这不是连续域认证。Reference 在 `13.75e6,-0.015625` 和独立留出点的额外闭合迭代上均出现积分步长限制；Fast 成功率不应与 Reference 可积分域混为一谈。下一步应沿 14M 端的更负倾斜边界继续小步定位，并在 Reference 不能提供闭合精度证据时保留为探索区。
