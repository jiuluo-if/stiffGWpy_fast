# CR0 14M 边界倾斜带扩展至 -0.0234375

## 区域与方法

固定 `cr=0`、`Omega_ch2=0.1201075`、`T_re=2000 K`、`r=0.01`、`kappa10=0.01`，筛查二维盒
`Omega_bh2 ∈ [13.875e6,14e6]`、`n_t ∈ [-0.0234375,0]`。CR0 下 `n_t` 是独立输入参数。

本轮不改物理方程、生产 Fast、Reference、验收阈值或参数含义。使用基准提交已有的尺度归一化背景与张量传播表示：其状态变换保持原背景方程、Fast 根条件和再加热匹配关系，本轮仅继续评估该统一数值机制的边界覆盖。

## 同输入 Fast 对照

11 个规则格点/内部点与独立 Sobol seed `20261148` 的 8 个留出点共 19 点，在旧失败基线 `872a70dc5ab3bb2ff9d3c0d78f05850341b42a45` 和新 Fast 上逐点对照：旧版 `0/19` 成功，新版 `19/19` 成功。旧版失败全部为 `nonfinite_background_primitive`。新 Fast 各点 H² 正且有限，最小采样值 `0.45321399346`，截止有限、75 个频点完整、零 warning。

精度带向负倾斜扩展，相较上一轮 `[13.875e6,14e6]×[-0.015625,0]` 增加相邻条带 `[13.875e6,14e6]×[-0.0234375,-0.015625]`。较低密度的 `13.75e6,n_t=-0.015625` Reference 仍步长下溢，因此保留在图中作盒外排除点，不计入本区域精度结果。

## Reference 精度

Reference 代码与设置未改，使用 `z_tail=8`、`rtol=1e-9`、`self_consistent=False`。在低密度边界、内部、14M 边界各作一次 Reference 映射，最大 root 相对残差 `1.63538e-5`，最大 75 频谱差 `6.37809e-4 dex`。独立 Sobol 留出点的 root 残差 `1.53261e-5`、谱差 `6.33857e-4 dex`。

14M 低倾斜边界再执行一次 Reference 闭合映射并成功，第二步残差 `6.85290e-8`。所有已测 root 误差低于 `2e-4`，谱差低于 `1e-3 dex`。这仍是有限样本证据，不是矩形内每一点的严格证明。
