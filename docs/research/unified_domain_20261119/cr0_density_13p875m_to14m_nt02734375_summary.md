# CR0 14M 边界倾斜带扩展至 -0.02734375

## 参数盒与数值路径

固定 `cr=0`、`Omega_ch2=0.1201075`、`T_re=2000 K`、`r=0.01`、`kappa10=0.01`，筛查
`Omega_bh2 ∈ [13.875e6,14e6]`、`n_t ∈ [-0.02734375,0]`。CR0 下输入 `n_t` 独立。

本轮没有改生产 Fast、Reference 或物理方程。复用已部署的尺度归一化背景和张量状态传播；这轮验证的是同一套数学等价数值表示在新相邻参数带的覆盖。固定点比较使用 Reference 映射 `F_ref(DN_eff)`：在 Fast 根处检查 `|F_ref(DN_fast)-DN_fast|/|F_ref(DN_fast)|`；14M 低倾斜角再把第一次 Reference 映射值作为下一步输入，检查第二步残差。Reference 设置保持 `z_tail=8`、`rtol=1e-9`、`self_consistent=False`。

## 旧/新 Fast 对照

规则网格与内部点 11 个，加上独立 Sobol seed `20261149` 的 8 个点，共 19 个相同输入。旧失败基线 `872a70dc5ab3bb2ff9d3c0d78f05850341b42a45` 在所有样本均因 `nonfinite_background_primitive` 失败；当前 Fast `19/19` 成功。当前所有样本 H² 正且有限，最小采样值 `0.45321399346`，截止有限，完整输出 75 个频率，无 warning。

相较前一轮已验收盒 `[13.875e6,14e6]×[-0.0234375,0]`，新添相邻倾斜带 `[13.875e6,14e6]×[-0.02734375,-0.0234375]`。旧 Fast 对该新增盒的样本仍全部失败。

## Reference 精度

三个密度端点/内部样本的 Reference 映射最大 root 残差 `1.66487e-5`，最大谱差 `6.38373e-4 dex`。独立 Sobol 点残差 `1.47631e-5`，谱差 `6.35914e-4 dex`。14M 低倾斜角继续做的第二次 Reference 映射成功，闭合残差 `2.24471e-7`。这些低于 root `2e-4` 和频谱 `1e-3 dex` 门槛。

盒外较低密度负倾斜点仍受 Reference 步长限制；它不计入本区域精度样本。采样结果不构成矩形内每点的连续域认证。
