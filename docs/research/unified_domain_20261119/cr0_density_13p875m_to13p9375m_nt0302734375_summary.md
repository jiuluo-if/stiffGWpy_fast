`Omega_bh2 ∈ [13.875e6,13.9375e6]`、`n_t ∈ [-0.0302734375,0]`。CR0 下输入 `n_t` 独立。

本轮生产 Fast、Reference 与物理方程均未改，继续使用已部署的尺度归一化背景/状态传播路径。Reference 映射记为 `F_ref(DN_eff)`，固定点残差按 `|F_ref(DN_fast)-DN_fast|/|F_ref(DN_fast)|` 计算。

## Reference 精度与边界

Reference 设置保持 `z_tail=8`、`rtol=1e-9`、`self_consistent=False`。低密度边界和内部代表点 root 残差最大 `1.54387e-5`，最大谱差 `6.38250e-4 dex`；独立 Sobol 点 root 残差 `1.27923e-5`、谱差 `6.27972e-4 dex`。在 `13.9375e6,-0.0302734375` 再作一次 Reference 闭合映射成功，残差为 `1.85257e-7`。

同倾斜 `14e6` 外角首次 Reference 映射触发 `Required step size is less than spacing between numbers`，已原样保留为盒外边界失败。Reference 仅核验有限代表样本；不声称连续域认证。
