# CR1 邻接密度边界筛查（候选 `b175f0b`）

## 有效域与 paired Fast 结果

固定 `cr=1`、`H0=67.32117`、`DN_eff=0`、`T_re=2000`、`DN_re=10`、`kappa10=0.01`，使用 Fast `h=0.005`、`z_tail=5`、`goal/PCHIP`、`tol=1e-6`、2 线程和 `physical_guard=True`。`n_t=0` 是 API 输入，CR1 实际派生倾斜为 `-0.00125`；全部 preflight 有限截止 `N_inf=68.81383977`，候选 `H²` 正有限，未触发数学无效或物理 guard 拒绝。

旧版基线 `872a70dc5ab3bb2ff9d3c0d78f05850341b42a45` 与现源码 `51c90300076278057ab1fc94f4d7ca3605a82cd6` 同输入配对：

- 邻接方块 `[7e5,8e5]²`：3×3 网格和两个内部点 `0/11→11/11`；独立 scrambled Sobol 留出（seed `20261122`）`0/8→8/8`。
- 旧版 19 点均为 `nonfinite_background_primitive`，且旧版 `H²` 正有限；候选无失败、76 个频率节点完整、无警告。候选屏幕运行 P50 约 `94.6 ms`，最大样本约 `99.8 ms`。
- 更高相邻方块 `[7e5,1.3e6]²` 的 Fast screen 也是 `0/19→19/19`，但这不等于精度合格；见下方边界拒绝结果。

## 当前源码 z8 Reference 精度

旧 CR1 工件源码哈希不匹配，因此不复用其数值。按当前源码的 Fast 根和保存的同一 76 点频率数组执行 Reference `z_tail=8, rtol=1e-9`，再迭代 map 到第三次：

| 邻接区样本 | Fast 根相对第三次 map | Fast 根处谱最大误差 | 第二至第三次 map 闭合差 |
|---|---:|---:|---:|
| 对角线 `(750k,750k)` | `1.3406e-4` | `9.0187e-4 dex` | `6.6741e-8` |
| 方块高角 `(800k,800k)` | `1.8543e-4` | `9.1571e-4 dex` | `1.7021e-7` |
| 独立 Sobol 高和留出 `(784.9k,799.7k)` | `1.7738e-4` | `9.1032e-4 dex` | `1.2972e-7` |

三点通过根误差 `2e-4` 和谱误差 `1e-3 dex` 门槛。采样边界的高角点距离根门槛约 `1.46e-5`，因此结论严格限于目前方块和样本，不外推到更高总密度。

## 更高密度区域拒绝

当前源码在 `[7e5,1.3e6]²` 仍可输出，但 z8 Reference 在 `(1.3M,1.3M)` 的根差/谱差为 `6.7009e-4 / 1.1025e-3 dex`；独立 Sobol 点 `(1.1837M,1.2205M)` 为 `6.0345e-4 / 1.0878e-3 dex`。中间点 `(1M,1M)` 根差 `4.4352e-4`，即使谱差 `9.5404e-4 dex` 通过，根门槛仍失败。故该上方块不纳入本次有效扩域。

## 性能 A/B 与异常首轮

旧 WKB helper 与当前 WKB helper 在高角点和独立 Sobol 点以 2 线程、BLAS 1 线程、CPU affinity `[0,1]`、TBB、`goal/PCHIP`、物理 guard 相同配置交替做 100 次完整求解。两点 P50 候选/基线比为 `0.998/1.004`，P95 比为 `0.990/1.024`；根、频率和谱逐位一致。首点隔离新 Numba cache 的基线/候选首调为 `19.68/18.64 s`（含 JIT）。

保留的 32 对先导运行中，高角点独立 P95 比为 `1.052`，超过门槛；扩到 100 对后为 `0.990`。100 对的成对比率 P95 仍有调度尖峰（高角点 `1.044`、Sobol `1.070`），所以只将 side-wise P50/P95 作为本报告的计时门槛结果，并显式保留这项尾部波动风险。生产源码没有更改；本 A/B 量化当前 WKB 守卫的区域成本，不把它归因成 CR1 背景扩域的唯一成因。

## 数学机制及证据边界

成功/失败机制沿用统一背景表示：在平滑支用 `sigma = 1 - (d ln H²/dN)/3` 重建 `∫sigma dN`；再加热前仍取精确 `sigma=1`，转折位置保持原样；指数尺度逼近 binary64 范围时自动切换相对背景表示。旧点 H² 正而旧 primitive 不可表示，候选因此跨过的是数值表示边界，不是物理截止或 `H²≤0`。

本轮没有改生产算法，也没有引入新的外部数值方法，因此没有新增论文来源。有限 screen 与三点 Reference 支持 `[7e5,8e5]²` 邻接方块；不证明连续区域，也不支持 `[7e5,1.3e6]²` 的准确求解能力。
