# CR0 负倾斜带密度上界扩展至 13.9921875M

## 参数区域与数值方法

固定 `cr=0`、`Omega_ch2=0.1201075`、`T_re=2000 K`、`r=0.01`、`kappa10=0.01`，筛查
`Omega_bh2 ∈ [13.875e6,13.9921875e6]`、`n_t ∈ [-0.0302734375,0]`。CR0 下输入 `n_t` 独立。

本轮 Fast/Reference 生产代码和物理方程均未改。继续使用已部署的统一尺度归一化背景/状态传播路径。Reference 映射 `F_ref(DN_eff)` 的 Fast 根残差按 `|F_ref(DN_fast)-DN_fast|/|F_ref(DN_fast)|` 计算。

## Fast 对照

11 个规则格点/内部点与独立 Sobol seed `20261153` 的 8 个样本，共 19 个同输入旧/新 Fast 对照。旧版 `0/19` 成功，新版 `19/19`；旧失败均为 `nonfinite_background_primitive`。新 Fast H² 正且有限，最小采样值 `0.45321399346`，截止有限、75 个频率完整、零 warning。

相较上轮，密度边界从 13.984375M 延到 13.9921875M。`14M,n_t=-0.0302734375` 的 Reference 首次映射仍失败，因此不纳入精度扩域盒。

## Reference 精度

Reference 设置保持 `z_tail=8`、`rtol=1e-9`、`self_consistent=False`。既有下密度边界和内部样本、13.9921875M 新上界、独立 Sobol 留出均通过：最大 root 残差 `1.67385e-5`，最大谱差 `6.38250e-4 dex`。新上界第二次 Reference 闭合映射成功，残差 `1.88552e-7`。

这些是有限样本精度证据，不是对盒内所有参数点的证明。

## 性能

同硬件、双线程 TBB、持久进程、每例 3 次预热，运行 500 对交替完整 Fast 求解。基线 `59a23aec2300f08b50124d7f35dec4b228388d37`，候选 `90a4c543dcb3277dc8afbad8bc2a7911d8d97f02`。新增区域最大 P50/P95 比 `0.996593/1.002441`，可信 CR0 控制 `0.996810/0.988929`。root、频率网格和谱逐位相同；首个冷启动求解基线 `20.452 s`、候选 `20.422 s`。

完整输入、筛选输出、Reference 映射、500 对计时、图和 SHA256 manifest 均随本摘要保存。
