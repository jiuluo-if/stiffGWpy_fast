# CR0 负倾斜带密度上界扩展至 13.99609375M

## 参数盒

固定 `cr=0`、`Omega_ch2=0.1201075`、`T_re=2000 K`、`r=0.01`、`kappa10=0.01`，筛查
`Omega_bh2 ∈ [13.875e6,13.99609375e6]`、`n_t ∈ [-0.0302734375,0]`。CR0 下输入 `n_t` 独立。

本轮没有修改生产 Fast、Reference 或背景/传播方程，继续复用已部署的统一数值表示。固定点误差使用 Reference 映射 `F_ref(DN_eff)` 的残差 `|F_ref(DN_fast)-DN_fast|/|F_ref(DN_fast)|`。

## Fast 区域扩展

11 个规则格点/内部点与独立 Sobol seed `20261154` 的 8 个样本共 19 点。同输入旧 Fast `0/19` 成功，新 Fast `19/19` 成功；旧失败全部为 `nonfinite_background_primitive`。新 Fast 的采样 H² 正有限，最小值 `0.45321399346`，截止有限，75 个频率完整，零 warning。

这一轮将前一轮密度上界 `13.9921875M` 推进到 `13.99609375M`。14M 的同倾斜 Reference 首次映射仍失败，因此 14M 外角保持排除。

## Reference 精度

Reference 固定 `z_tail=8`、`rtol=1e-9`、`self_consistent=False`。低密度/内部/上界样本与独立 Sobol 留出最大 root 残差 `1.67385e-5`、最大谱差 `6.38250e-4 dex`。13.99609375M 新上界第二次闭合映射成功，残差 `1.15104e-8`。这些是有限样本结果，不是矩形连续域认证。

## 性能

同硬件、双线程 TBB、持久进程，每例 3 次预热和 500 对交替完整求解。基线 `59a23aec2300f08b50124d7f35dec4b228388d37`，候选 `90a4c543dcb3277dc8afbad8bc2a7911d8d97f02`。新增区域 P50/P95 最大比 `0.993932/0.989277`；可信 CR0 控制 `1.001524/0.979470`。root、频率网格和谱逐位相同。首个冷启动求解基线 `20.592 s`、候选 `20.515 s`。

同目录保留成对 Fast 筛选、Reference 映射、500 对原始计时、绘图和 SHA256 清单。
