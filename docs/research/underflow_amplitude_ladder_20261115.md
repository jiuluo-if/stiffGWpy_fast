# `cr=0` 下溢振幅阶梯筛查

日期：2026-11-15

## 问题与设计

检验 `r A_s` 已在 float64 中舍入为零、但输入 `r>0` 的对数振幅模式，是否随非零次正规 `r` 接近最小正 float64 而连续；再与精确 `r=0` 路径分开。使用既有 `n_t=17.38, cr=0` 的原生 235 点网格，不更换频率节点。阶梯为 `r={1e-316,1e-317,1e-318,1e-320,5e-324,0}`，所有非零样本均有存储 `A_t=0`。分别测完整自洽 Fast 返回值和固定在基准根 `DN_eff=0.027412228089632874` 的单次映射。

## 结果

- 五个非零次正规样本均完成 Fast；记录到 235 个有限对数谱节点，无 solver failure。最小正 `r=5e-324` 的自洽映射根为 `1.3543440e-9`；`r=0` 精确零支路返回零根和零有限谱节点，失败原因为空。该分支能把 exact zero 与非零 underflow 区分开。
- 固定相同背景下，各非零振幅的归一化对数谱与 `r=1e-316` 基准最大差为 `5.7e-14` 至 `1.14e-13 dex`；对应 `DN_gw` 按 `r` 线性缩放后的比例为 `0.99999999999994` 至 `1.00000000000002`。这直接支持 `cr=0` 同一固定背景内单位振幅传播/恢复尺度的线性齐次性，覆盖本阶梯这些离散振幅。
- 在同一个冻结背景和 235 个原生节点上，另用单位振幅 Cartesian Reference 直接求解，再以各输入振幅和倾斜缩放。Fast z5 对 Reference z8 的最大谱差在五个非零振幅上均为 `0.00048044795 dex`，积分映射相对差均为 `8.35e-7`；固定背景下归一化后的差异相同，因为传播方程与积分对正振幅齐次。它通过该网格/尾深/背景点的离散门槛，但不替代其他根和频率网格的 Reference 收敛证据。
- 自洽根与振幅比例的归一化比为 `0.9999999999883` 至 `0.9999999999895`，映射根残差按求解器返回值为 0。自洽归一化谱相对最大差为 `0.00191–0.00192 dex`；它来自振幅改变后根与背景改变，不能用固定背景的线性等价性消去。该变化也高于本任务 `1e-3 dex` 的筛查门槛，故不据此宣称跨振幅的形状精度通过。

## 结论和限制

本筛查支持：在一个 `cr=0,n_t=17.38` 点、同一 235 节点网格及固定背景下，对数域振幅恢复保持线性缩放，直到 float64 最小正次正规输入；独立单位振幅 Reference 的缩放对照也在此离散背景上通过 `1e-3 dex` 谱差门槛；精确零仍走单独解析路径。它没有在阶梯每个振幅对应的自洽根上做 Reference，亦未完成各根的 469/937 网格收敛、根迭代容差扫描和独立留出，因此不是新的根精度认证或连续振幅域认证。自洽谱最大差揭示背景改变不能忽略，后续必须在不同根上分别做 Reference/频率收敛。
