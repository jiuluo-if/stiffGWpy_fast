# 下溢阶梯自洽根容差筛查

日期：2026-11-15

## 方法

在与振幅阶梯相同的 `cr=0,n_t=17.38`、直接 235 节点网格上，对 `r={1e-316,1e-318,5e-324}` 分别使用外层 `tol={1e-5,1e-7,1e-9,1e-11}` 求根。对每个返回根再冻结 `DN_eff` 独立算一次 Fast 映射，计算 `DN_gw(root)/root−1`。同时计数 `gen_fast` 被调用的次数，作为背景传播评估次数；这能显示外层确实重新评估了背景，不以返回的 `DN_gw` 自身当作独立残差。

## 结果

- 每个振幅的四种 `tol` 得到完全相同的 float64 根：`r=1e-316` 为 `0.027412228089632874`，`1e-318` 为 `0.0002741219423071541`，最小正数 `5e-324` 为 `1.3543440396198841e-9`。
- 每个根的独立固定背景映射相对残差为 `0`，或 `−2.22e-16`。这些是单网格、同一 Fast 离散算子的固定点闭合，不是 Reference 根残差。
- `gen_fast` 次数：前两个振幅每个 tol 都是 2 次；`r=5e-324` 在 `tol=1e-5,1e-7,1e-9` 是 1 次，在 `tol=1e-11` 是 2 次。最后者因初始估计已在当前停止标准内而提前结束，收紧到 `1e-11` 后触发一次额外重算，根数值未改变。这说明三点上的容差参数确有停止判定作用，但没有造成可观测根移动。

## 限制

频率离散仍在 235 点；Reference 仅对部分根完成 235 点比较，未在每个 tol 重算，也未完成 469/937 Reference 和 Reference z8→z10 尾部收敛。结果是这三个离散样本的根闭合证据，不是根唯一性、收缩映射证明或参数域认证。
