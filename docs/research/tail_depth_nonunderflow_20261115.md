# 常规振幅参数点尾深复核

日期：2026-11-15

## 目标和参数

独立检查在常规振幅、自由倾斜分支上，`z_tail=8` 的尾部精度收益是否也存在。参数为 `r=0.01`、`A_s=2.100549e-9`、`n_t=0`、`cr=0`、`T_re=2000`、`DN_re=20`、`kappa10=0.01`；Fast 使用 76 个原生 goal 频率点和单线程。Fast 自洽根为 `DN_eff=0.002369124823794334`，内部 `dn_converged_delta=0`。

## 固定根对照

| 方案 | 映射 `DN_gw` | 相对根残差 | 直接 Reference 比较 |
|---|---:|---:|---:|
| Fast z5 | 0.002369124823880245 | `3.63e-11` | 对 Reference z10 最大 / P95 谱差 `0.002321/0.000351 dex` |
| Fast z8 | 0.002369112474432948 | `−5.21e-6` | 对 Reference z10 最大 / P95 谱差 `0.000378/0.000239 dex` |
| Reference z8 | 0.002369820834522339 | `+2.94e-4` | z8→z10 最大 / P95 谱变化 `0.000243/0.000162 dex` |
| Reference z10 | 0.0023691343442821195 | `+4.02e-6` | z10 作为本次尾部复核基准 |

Reference 的 z8 映射根残差超过本项目 `2e-4` 根相对门槛；z10 后降至 `4.02e-6`。Fast z8 相对 z10 Reference 的根映射残差为 `−5.21e-6`，频谱最大差也低于 `1e-3 dex`。因此这个普通振幅样本再次显示 z5 的尾误差会超过谱门槛，而 z8 通过了该离散网格对照。

一个额外蓝倾斜尝试 `n_t=0.5` 在正式 `physical_guard=True` 下被 `shared_Neff_guard` 拒绝，没有生成可比较的频谱或根。该失败单独保存在 JSON 的 `rejected_root_preflight_trial` 中，没有把失败当作精度结果。

Reference z8 / z10 全网格运行时间分别为 `26.95 s` / `175.81 s`，单线程、76 个频点；二者不是同源后端的性能对照。Fast 此次仅有单次运行时间，不用于速度结论。本样本不证明连续参数域，也不足以更改 Fast 默认尾深；还需覆盖 `cr>0` 一致性分支，并对 Fast z5/z8 做重复同资源 A/B。
