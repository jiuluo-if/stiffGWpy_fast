# 精度边界

求解器不承诺在整个参数空间内具有一致精度。精度结论必须绑定实际核验过的引擎、配置、参考约定、参数点和频率网格。

默认 `fast` 档位由核心回归测试和物理极限测试保护。尤其是 `tests/test_fast_residual_estimator.py` 与 `tests/test_wkb_singular_mode_completion.py` 会将指定输出和 `tests/data/` 中固定的独立参考样本比较。这些检查用于保护已知数值行为，不代表对未经测试的连续参数区域作出认证。

精度对照应使用独立的 `reference` 引擎。`lsoda` 用作兼容性和回归路径，不视为独立真值。提出新的精度结论时，应先在本地研究归档保留输入参数、准确配置、参考约定、源码提交和机器可读比较数据，再评估是否需要增加针对性回归样本。
