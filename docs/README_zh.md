# 文档

本目录保留软件和数值方法维护说明：

- `physics.md`：物理模型与假设。
- `numerical_method.md`：求解器与积分方法。
- `accuracy.md`、`accuracy_zh.md`：验证范围和结果解释边界。
- `cobaya.md`：可选 Cobaya 适配器。
- `reproducibility.md`：环境和验证规范。
- `test_coverage_matrix.md`、`test_coverage_matrix_zh.md`：核心测试职责。

批量研究输出和实验记录保存在独立的本地归档中。回归测试必需的固定样本存放于 `tests/data/`。
